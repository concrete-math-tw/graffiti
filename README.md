# 《具體數學》邊注伴讀

Graham、Knuth 與 Patashnik 合著的 *Concrete Mathematics*（《具體數學》，第 2 版）每一頁的頁邊，都印著試讀初稿的學生（來自史丹佛、普林斯頓等六所大學）留下的「塗鴉」：雙關語、美國流行文化、文學典故、數學冷笑話。對非英語母語的讀者來說，這些往往是全書最難懂的部分。

這份伴讀替全書頁邊的 **557 則塗鴉**逐則作中文評註，寫給繁體中文、特別是台灣的讀者：

- **逐頁評註**：依章節與頁碼排列，說明旁邊正文在講什麼、哪個字被拿來玩、背後是哪段文化。
- **中文說法**：能在中文裡重現的笑點，附上中文版的講法。
- **文化小辭典**：棒球、美國硬幣、廣告品牌、影視漫畫、福爾摩斯、拉丁文縮寫……依主題整理，頁碼可點回條目。
- **英文雙關的五種套路**：把全書笑話歸納成幾種手法，讀懂這本書，也讀懂更多英文笑話。

## 怎麼讀

這是**伴讀**材料，請搭配原書閱讀：每則只引原文開頭幾個字，方便你在書上找到是哪一則。頁碼依原書第 2 版（第 32 刷）。
